# 📌 Project Overview

This project demonstrates a complete **Data Analytics workflow** using **Python**, **SQL**, and **Power BI**.

The dataset was cleaned and analyzed in Python, explored using SQL queries, and visualized through an interactive Power BI dashboard to generate business insights.
